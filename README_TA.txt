ME GROUPS - இலவச Cloud APK Build

இந்த ZIP ஒரு ஆரம்ப Demo Android app source. இது இன்னும் production-ready அல்ல.
பயன்பாட்டில் 20 உறுப்பினர்கள், மாதம் ₹1,000, ₹20,000 மாத வசூல்/பரிசு,
மாதம் 2 Company Chit, மற்ற மாதங்களில் ஒருவருக்கு ஒருமுறை lucky draw உள்ளது.
தகவல்கள் அந்த மொபைல் சாதனத்தில் மட்டும் சேமிக்கப்படும்; app uninstall/data clear செய்தால் இழக்கலாம்.
பணம் வசூல், வங்கி, பல மொபைல் sync, login, backup, audited draw ஆகியவை இல்லை.

மொபைலில் இலவசமாக APK பெற:
1. GitHub account உருவாக்கு / sign in செய்: https://github.com
2. GitHub-ல் New repository அழுத்தி பெயர் ME-GROUPS என்று வை; Public தேர்வு செய்து Create repository.
3. இந்த ZIP-ஐ unzip செய்து உள்ளே உள்ள எல்லா கோப்புகளையும் repository-க்கு upload செய்.
   GitHub mobile browser-ல் Add file > Upload files மூலம் கோப்புகளை upload செய்து Commit changes செய்.
4. Repository-ல் Actions tab திற. "Build ME GROUPS APK" workflow-ஐ தேர்வு செய்து Run workflow அழுத்து.
5. Build முடிந்ததும் அந்த run-ன் கீழே Artifacts பகுதியில் ME-GROUPS-APK என்ற ZIP-ஐ download செய்.
6. ZIP-ஐ திறந்து app-debug.apk-ஐ install செய். Android கேட்டால் அந்த browser/file manager-க்கு Install unknown apps அனுமதி கொடு.

குறிப்பு: GitHub-ன் இலவச usage limits மற்றும் account verification நிபந்தனைகள் பொருந்தும்.
உங்கள் அசல் ME GROUPS logo-வை app-ல் சேர்க்க, logo image-ஐ பின்னர் drawable/asset-ஆக சேர்க்க வேண்டும்.
உண்மைப் பணச் சீட்டு நடத்துவதற்கு முன் பொருந்தும் Chit Funds சட்டம் மற்றும் மாநில பதிவு விதிகளைச் சரிபார்க்கவும்.
